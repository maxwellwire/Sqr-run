# 🐿️ SQR RUN

SQR RUN is an original mobile-first squirrel endless runner built for the SQR community.

Players create an account, enter an EVM wallet address, choose a username and PIN, then compete for the longest valid distance survived.

---

## Core Features

- Original squirrel endless-runner gameplay
- Mobile-first controls
- Jump
- Slide
- Collectibles
- Obstacles
- Increasing game speed
- Personal best distance
- Public leaderboard
- Seasons
- EVM wallet registration
- Username + PIN login
- Persistent secure sessions
- Server-side run validation
- Suspicious-run detection
- Admin dashboard
- Manual reward distribution architecture
- Share run results on X

---

## Important Gameplay Metric

SQR RUN does not use a traditional score as the primary competitive metric.

The main metric is:

**BEST DISTANCE SURVIVED**
